# Skills I chose (checked 2026-11-02)

Project: marketing emails for the 2nd edition of *The AI Agent Factory* (Panaversity). Practice mode only, no real email is sent.

## Use these

1. **Anthropic's marketing plugin** (`anthropics/knowledge-work-plugins`, 34.5K GitHub stars, updated today). It is published by Anthropic itself. It gives us `/marketing:campaign-plan`, `/marketing:email-sequence` and `/marketing:brand-review`, which cover planning, writing and reviewing the campaign.
2. **Resend's own skills** (`resend/resend-skills`, 209 GitHub stars, updated 4 days ago). The skill `resend` has 24.1K installs on skills.sh. Resend is the email service we send through, so its own skills are the safest source for sending. The star count is modest because it is a small, niche repository, but the publisher is the company itself.

Good backup for writing help: `coreyhaines31/marketingskills` (58K stars). It is well known and active, but it is one person's collection, not an official publisher.

## Avoid these

1. **`mbfinotti/advertising-skills@ad-budget-pacing`**: 24.9K installs but only **2 GitHub stars**. That gap is a warning sign, because installs can be inflated. It is also about paid ads, and our campaign is email only.
2. **`open.feishu.cn@lark-mail`**: the top "email marketing" result with 840.6K installs. It is a connector for Lark/Feishu mail, not for marketing campaigns, and its publisher is a bare domain rather than a GitHub repository I could check. A big install number does not mean it fits our job.

(Also not relevant: `mattpocock/skills@grill-with-docs`, 1.3M installs for "campaign plan". It is a popular repo, but it is not a marketing skill.)

## How I decided

1. **Who publishes it?** Prefer official publishers (Anthropic, Resend) and well-known maintainers. Be careful with unknown names and bare domains.
2. **Do the GitHub stars match the install count?** Thousands of installs with a handful of stars is suspicious. Open the repository and look at its stars and last update.
3. **Does it do what I need, and is it still current?** Read the skill's description to check it fits the job. Check that it has not been renamed, merged or abandoned. Install only after that.

Note: today `email-sequence` (55.1K installs) and `emails` (82.4K) both appear under `coreyhaines31/marketingskills`. Skills get renamed or merged, so re-check before installing.
